# Чек-листы дымового тестирования и критического пути

> Документ 4 из 4. Слой — периферия.

## 1. Дымовое тестирование

Быстрая проверка работоспособности после сборки, до 10 минут; выполняется до содержательных проверок.

**Развёртывание**

- [ ] `docker compose up -d` проходит без ошибок, `docker compose ps` — все сервисы и БД в состоянии `Up (healthy)`
- [ ] PostgreSQL принимает соединения, стартовые миграции применились
- [ ] RabbitMQ UI доступен, очереди `transaction-log` и `card-notifications` объявлены

**Доступность сервисов**

- [ ] health-check отвечают Gateway, Switch, Authorization, Card Management, Merchant Acquirer, Terminal Simulator, Transaction Logger
- [ ] `/actuator/health` отвечают Bin Lookup и Notification Service
- [ ] Dashboard отдаёт страницу без ошибок в консоли

**Тестовые данные**

- [ ] генератор создал ≥ 20 карт, все PAN проходят проверку по Луну
- [ ] среди карт есть все статусы, включая INACTIVE и BLOCKED
- [ ] список карт с пагинацией возвращает корректные `total` и `cards`
- [ ] симулятор терминалов отправляет пачку транзакций и получает ответы

**Минимальная сквозная проходимость**

- [ ] транзакция доходит до Authorization и получает решение
- [ ] одобренная и отклонённая транзакции появляются в Transaction Logger с кодом
- [ ] Dashboard отображает статистику и последние транзакции
- [ ] `scripts/smoke-test.sh` завершается `🎉 ALL CHECKS PASSED`
- [ ] метрики отдаются Prometheus, логи поступают в Loki

## 2. Критический путь

Ключевые сценарии процессинговой цепочки; проверяется после дымового тестирования.

**Покупка**

- [ ] транзакция проходит цепочку: терминал → Gateway → Switch → Authorization → Card Management → Transaction Logger
- [ ] при достаточном балансе и валидных лимитах авторизация одобряется
- [ ] одобренная транзакция получает RRN и authCode
- [ ] баланс уменьшился ровно на сумму транзакции, счётчики лимитов обновились
- [ ] запись доступна в поиске Logger по RRN, Dashboard учёл транзакцию

**Отказы**

- [ ] отказ по недостатку средств не изменяет баланс
- [ ] отказ по превышению лимита не изменяет баланс и счётчики использования
- [ ] отказы по BLOCKED, INACTIVE и просроченной карте различаются по коду
- [ ] отказ по ненайденной карте отличается от недоступности Card Management
- [ ] все отказы попадают в Logger с различимыми причинами

**Возврат**

- [ ] возврат возвращает сумму на баланс и снимает её из учёта лимитов
- [ ] повторный возврат по тому же RRN не даёт двойного зачисления
- [ ] при недоступности Logger Switch инициирует откат зарезервированных средств
- [ ] баланс после цикла «покупка → возврат» совпадает с исходным

**Недоступность зависимостей**

- [ ] при недоступности Card Management транзакция отклоняется с таймаутом эмитента
- [ ] при недоступности Bin Lookup авторизация идёт по данным BIN из таблицы Switch
- [ ] при недоступности RabbitMQ события копятся в outbox и переходят в FAILED после retry
- [ ] после восстановления зависимости система работает без перезапуска

**Целостность данных**

- [ ] сумма резервов согласуется с суммой одобренных транзакций
- [ ] число записей в Logger согласуется с числом обработанных транзакций
- [ ] мягко удалённые карты не участвуют в транзакциях и не видны в списках
- [ ] данные Dashboard не расходятся с данными Logger

## 3. Классы верхнего уровня для периферии

Полная модель для периферии не строится: поведение сервисов проще, эффект попарного тестирования несоразмерен затратам. Классы ниже задают основу чек-листов выше.

| Сервис | Классы верхнего уровня | Приоритет |
|---|---|---|
| Gateway | запрос валиден / невалиден; Switch доступен / недоступен; ответ проксируется без искажений | P2 |
| Switch | BIN найден / не найден; Authorization доступен / недоступен; Logger доступен / недоступен | P1 |
| Terminal Simulator | размер пачки; канал POS / ATM / ECOM; пул карт доступен / пуст | P3 |
| Merchant Acquirer | мерчант найден / не найден; MCC задан / отсутствует | P3 |
| Bin Lookup | BIN известен / неизвестен; отвечает / отвечает ошибкой / недоступен | P2 |
| Notification Service | событие создания / обновления / удаления карты; брокер доступен / недоступен | P3 |
| Transaction Logger | приём через REST / RabbitMQ; поиск по RRN, PAN, статусу, датам; страница пуста / заполнена | P2 |
| Web Dashboard | статистика отображается / API недоступен; таблица заполнена / пуста | P3 |
